# Cliente web - SI-DLYTime

Aplicación React 18 construida con **Vite**.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # genera dist/
npm test         # Vitest
```

La URL del API se configura con `VITE_API_URL` (ver `.env.example`).

Documentación completa del proyecto en el [README raíz](../README.md).
